# Noum motion assets — V8 "Sticker Bold"

Brand-exact vector animations and the UI sound kit for the approved V8 language.
Lottie generated by `tools/gen_noum_lottie_v8.py`; sounds by `tools/gen_noum_sounds.py`.
Both verified before commit — the Lottie frame-by-frame in `lottie-web`, the audio via `volumedetect`.

The cold-launch handoff is authored separately by
`tools/gen_noum_splash_lottie.py`. It is the canonical LottieFiles/Figma
motion handoff; the app mirrors its bounded keyframes natively in SwiftUI to
avoid adding a one-off runtime dependency during cold start.

## The motion vocabulary changed

V6.1 was glossy, so its motion breathed and glowed. **Stickers do not breathe or glow — they
LAND, PRESS and PEEL.** Anything that pulses forever belongs to the old language and is a bug here.

| Beat | What happens |
|---|---|
| **Land** | drops from y −70, opacity 0→1 in ~180ms, scale 1.06 → 1.0, rotation settling from about double its final angle |
| **Shadow tell** | the stamped shadow appears only **at the contact frame** (0→1 over 60ms). It never travels with the object |
| **Press** | the sticker pushes down onto its shadow; the shadow offset collapses toward 0 |
| **Stamp** | reward only — scale 1.5 → 0.94 → 1.0 in ~220ms with a −3° rotation kick, *after* the ground colour flips |
| **Peel** | dismissal — a short lift and rotate away |

Everything settles. No perpetual ambient loops.

## Lottie files

| File | Moment | Size |
|---|---|---|
| `noum-sticker-land-blue.json` | any blue sticker landing (hero card, drill row) | 2.5 KB |
| `noum-sticker-land-gold.json` | reward-tinted sticker landing (streak, XP) | 2.5 KB |
| `noum-reward-stamp.json` | rep complete — die-cut disc stamps in, 16 chips scatter | 24 KB |
| `noum-unlock-stamp.json` | path node unlocks — slot fills, gold seal stamps on | 6 KB |
| `noum-splash-conversation.json` | cold launch — 5.25s mouth-only conversation, camera push into the speaking point, orange/yellow blended field, large lowercase wordmark | generated |

Pure shape layers, no rasters, no third-party licence. Recolour at runtime rather than re-exporting:

```swift
let provider = ColorValueProvider(UIColor(named: "RewardGold")!.lottieColorValue)
view.setValueProvider(provider, keypath: AnimationKeypath(keypath: "disc.**.Fill.Color"))
```

**Reduced Motion:** do not play — show the final frame and keep the haptic.

```swift
LottieView(animation: .named("noum-reward-stamp"))
    .currentProgress(reduceMotion ? 1 : nil)
```

## Sound kit — `Noum/Resources/Sounds/`

> **Unwired, and it conflicts with the shipping audio architecture — read this
> before bundling it.** The app already synthesizes its interaction cues at
> runtime: `Noum/InteractionSoundEngine.swift` renders every cue procedurally
> through an `AVAudioSourceNode`, with a mic-suppression gate, a user toggle,
> an `.ambient` session so the silent switch wins, and unit-tested envelope
> budgets. `SoundscapeEngine` does the same for ambience. Zero asset weight,
> no licensing surface. Bundling ~500 KB of WAVs would be a second, parallel
> audio path with none of those gates — precisely the fragmented ownership
> the architecture rules forbid.
>
> The generated kit is committed because the *sound design* in it is worth
> keeping (pitch envelopes, layered transient/body/sub, 3 variants per
> repeated cue). The likely right move is to port those envelopes into
> `InteractionCueSynth` as new `InteractionCue` cases rather than ship the
> files. Decide that before adding anything here to a resource build phase.


Dry and matte to match the material. The glossy kit's reverb tails were removed: a sticker
landing on paper has almost no ring.

| Cue | Haptic | Fires on |
|---|---|---|
| `land` | `.impact(.light)` | a sticker arrives |
| `stamp` | `.impact(.medium)` | a sticker lands with weight (hero, chapter) |
| `press` | `.selection` | any button press |
| `tick` | `.impact(.rigid)` | each countdown tick |
| `unlock` | `.notification(.success)` | a node or milestone opens |
| `reward-stamp` | `.impact(.heavy)` | the celebration number stamps in |
| `peel` | `.impact(.soft)` | dismissal |
| `slide` | — | screen transition |

Fire the sound and its haptic from the **same state change** that starts the animation — never
schedule either off the animation clock.

## Authoring gotchas (each one cost a debugging round)

- **Every keyframe must carry easing — including the first.** An opacity keyframe at `t=0` with
  no `i`/`o` silently kills the entire layer: paths render with empty `d` and no fill. This is the
  single most expensive bug in the format.
- **`layers[0]` renders on top** (After Effects stacking). A checkmark listed after its disc is invisible.
- **Layer transforms need three components** (`[x,y,z]`); group transforms inside `shapes` take two.
- **Trim-path draw-on** works as `[sh, st, tm, tr]` with `e` animated 0 → 100.
- A **screenshot shows base values, not the timeline end** — park animated elements in a resting
  base transform or they sit wrong at rest.
- White strokes on a white ground look "missing" — diagnose on a dark background first.
